## Issues Found & Recommended Fixes

### 🔴 CRITICAL — cinereview sitemap still 80.8% below baseline (8,064 vs ~42,000)

**Status:** Persisting from last week. Slight recovery (+6.3%) but far from resolved.  
**Severity:** Critical — Google is still unaware of ~33,900 movie/person pages.  

**New data point:** `/ar/movies/inception` now confirmed 200 OK, so dynamic movie pages are live and accessible — the problem is in sitemap generation, not page availability.

**Likely root cause:** The sitemap generation code is not pulling the full TMDB dataset. Possible causes:
- TMDB API returning paginated results with only the first N pages fetched
- Sitemap generation runs out of time/memory and exits early
- A build-time env variable (e.g. API key or page limit) is capping the output

**Recommended actions:**
1. Check TMDB API call in sitemap generation — verify pagination fetches ALL pages, not just the first
2. Check Vercel function logs during build for timeout/memory errors
3. Monitor week-over-week: if count keeps rising ~6% per week, it may self-recover over ~2 months; if it stalls, investigate the cap

---

### 🟠 HIGH — aitools-ar sitemap stagnant at 352 URLs (baseline ~1,009)

**Status:** Persisting from last week. Count is essentially flat (355 → 352), not recovering.  
**Severity:** High — ~657 tool/comparison/blog pages missing from sitemap for 2+ weeks.

**This is now more urgent:** Zero recovery in one week suggests the low count is a fixed cap or data source issue, not a transient problem.

**Recommended actions:**
1. Check sitemap generation code — count how many tools, comparisons, and blog posts are in the database vs. what's included in the sitemap
2. Look for any `limit` or `take` parameters in the Prisma/database queries used during sitemap generation
3. Check if comparison pages (`/ar/compare/*`) and blog pages (`/ar/blog/*`) are actually being generated — the sitemap structure shows these sections exist
