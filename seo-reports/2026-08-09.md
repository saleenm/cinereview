## Issues Found & Recommended Fixes

### 🔴 CRITICAL — cinereview sitemap URL count dropped ~82% (42,000 → 7,586)

**Severity:** Critical — Google loses discovery of ~34,400 movie/person pages.  
**Likely causes:**
- Sitemap generation is filtered or capped (e.g., API rate limit hit during build, env var missing in production)
- Movie pages are now dynamically excluded (robots `Disallow`, `noindex`, or sitemap filter logic changed)
- TMDB or data source returned fewer records during the last sitemap build

**Recommended actions:**
1. Trigger a fresh sitemap rebuild and compare output count immediately
2. Check the sitemap generation code for any new filters, limits, or changed data sources
3. Verify movie pages individually (e.g., `/ar/movies/inception`) are returning 200 (currently unverifiable from this environment — test from a browser or external checker)
4. Check Vercel function logs for errors during sitemap generation

---
