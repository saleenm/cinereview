## Issues Found & Recommended Fixes

### 🔴 CRITICAL — cinereview sitemap still 78.9% below baseline (8,882 vs ~42,000)

**Status:** Recovering at ~10% per week (+818 this week), but still far below baseline.  
**Severity:** Critical — Google is still unaware of ~33,100 movie/person pages.  

**Trend analysis:** 3-week recovery trajectory: 7,586 → 8,064 → 8,882. Rate is accelerating (+478 then +818). At this pace, full recovery would take approximately 5–6 more months. **There is likely still a root-cause cap** that is being slowly worked around.

**Recommended actions:**
1. **Investigate the data source cap**: the sitemap is growing but hasn't auto-recovered quickly. Check if a TMDB API pagination limit or build-time env variable is still capping total pages fetched.
2. **Check Vercel build logs** for timeout or memory errors during sitemap generation.
3. If the cause remains unknown and growth plateaus again, consider regenerating the full sitemap outside the build process (e.g. a scheduled cron job that writes to a static file).

---

### 🟠 HIGH — aitools-ar sitemap completely stagnant (352 URLs for 3 consecutive weeks)

**Status:** Flat for 3 weeks — 355 → 352 → 352. Not recovering at all.  
**Severity:** High — ~657 tool/comparison/blog pages missing from sitemap with no sign of recovery.  

**This is now confirmed as a fixed cap or broken data source**, not a transient build issue. The sitemap is being regenerated (last modified timestamp updated) but always produces 352 URLs.

**Recommended actions (escalated urgency):**
1. **This needs direct code investigation.** Open `app/sitemap.ts` (or equivalent) and check for any `limit`, `take`, `first`, or page-size cap on the database queries that generate sitemap entries.
2. Compare the number of tools in the database vs. the number in the sitemap — if the database has >1,009 tools but only 352 appear, the query has a hard cap.
3. Check if comparison pages (`/ar/compare/*`) and blog pages (`/ar/blog/*`) are being included — if the baseline was ~1,009 and the current count is 352, large content categories are being dropped entirely.
